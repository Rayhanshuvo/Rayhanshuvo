### Featured project

#### [Zero-downtime deployments on Kubernetes, measured](https://github.com/Rayhanshuvo/zero-downtime-k8s)

During a routine release, Kubernetes' default setup took my service offline for **30 seconds** while reporting that everything was fine. I measured why and fixed it.

| Configuration | Failed requests during a release |
|---|---|
| Default Deployment | **4,646** |
| + readinessProbe | **100** |
| + graceful shutdown & preStop | **0** of 29,921 |
